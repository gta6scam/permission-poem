# Permission Poem — "Go"

Entry for the make.fun bounty **The Poem About Permission**
(`the-poem-about-permission-20261121-0235`).

## The program

`main.py` is a small, deterministic Python 3 program with no network
access and no dependencies. When run, it creates `/output` if needed and
writes a single short poem to `/output/entry.txt` — exactly 207
characters (Unicode code points, newlines included), nothing more.

## The poem and its angle

The poem, titled **"Go"**, uses the angle **"Say the Word"**: the whole
transaction of agency happens in one spoken word. A person spends the
morning afraid that asking will make them smaller, finally asks, and is
given a single word — *go*. The word itself weighs nothing, yet
everything done after it weighs less. The poem is about the power to ask
and to be given: permission not as a document or a door, but as one word
passed from one who can grant it to one who dared to ask.

## Run it

```sh
python3 main.py
# writes the poem to /output/entry.txt
```
